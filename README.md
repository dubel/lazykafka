# lazykafka-dist

# Usage
Homebrew (macOS/Linux)
brew tap dubel/tap
brew install lazykafka
Linux (Debian/Ubuntu)
Go to the releases page of your public repo (https://github.com/dubel/lazykafka-dist/releases), download the .deb file, and run:

sudo dpkg -i lazykafka_*.deb
Linux (RHEL/CentOS/Fedora)
Go to the releases page of your public repo, download the .rpm file, and run:

sudo rpm -ivh lazykafka_*.rpm
Linux (Arch Linux)
Go to the releases page of your public repo, download the .pkg.tar.zst file, and run:

sudo pacman -U lazykafka_*.pkg.tar.zst
